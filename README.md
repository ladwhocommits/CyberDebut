## MODULE 1: Start Your Cyber Security Journey


### 🛡️ Lab 01: Introduction to Offensive Security
* **Key Takeaway:** Offensive Security is about thinking like an attacker to find weaknesses before real hackers do. The opposite, defensive security, is about keeping hackers out and acting when it goes wrong. One common thing Hackers look for on a website is pages that are not linked . We used "dirb" in this module to scan a url in order to find pages that are not linked . This is a brute forcing tool . Requiring Login to Certain pages can help to strengthen the defense of the url .

### 🛡️ Lab 02: Introduction to Defensive Security
* **Key Takeaway:** Security Operations Centre (SOC) is  the central hub for defending an organisation.  In defensive security, we share information about attackers,  This is known as threat intelligence . The monitoring dashboard shows a history of what the attacker is trying to find on our website. Incident reports allow us to reflect, train, and detail any attack and it  is helpful for us in defensive security .
